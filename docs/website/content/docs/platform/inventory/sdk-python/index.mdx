`tetherto-qvac-sdk` is the Python client for the QVAC SDK worker: the same contract as `@qvac/sdk`, asyncio-native, with the inference running in the worker.

[Repository](https://github.com/tetherto/qvac/tree/main/packages/sdk-python) · [PyPI](https://pypi.org/project/tetherto-qvac-sdk/) · [Product documentation](/sdk)

## Documented versions

The package carries no version of its own: it is stamped from the `@qvac/sdk` release it speaks to, so its numbers are the SDK's.

| Version | Release |
| --- | --- |
| [v0.17](/platform/inventory/sdk-python/v0.17/) | Not cut yet — taken from [`main`](https://github.com/tetherto/qvac/tree/main/packages/sdk-python) |
| [v0.16](/platform/inventory/sdk-python/v0.16/) | [`sdk-v0.16.0`](https://github.com/tetherto/qvac/releases/tag/sdk-v0.16.0) |

Patch releases are not listed. A version page carries the README of the release it names, and the [GitHub releases](https://github.com/tetherto/qvac/releases) hold what changed in each patch.
