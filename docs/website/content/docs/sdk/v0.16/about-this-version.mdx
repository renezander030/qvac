## Overview

You are reading the documentation for **`@qvac/sdk` v0.16**. Every page in this
section describes that release, and every link between these pages stays inside
it, so an example you copy from here matches the version you have installed.

The current release is documented in its own section, served without a version
in the URL: `/sdk/quickstart` is the current quickstart, and
`/sdk/v0.16/quickstart` is this one.

## Moving between versions

The version switcher sits at the top of the sidebar, above the navigation. It
lists every documented version of the SDK and marks the current one as
`(latest)`. Picking one keeps you on the same page where that version has it,
and lands on that version's overview where it does not.

## Which version you have

Read the version installed in your project rather than assuming it:

```bash
npm ls @qvac/sdk
```

If the answer is not `0.16.x`, switch to the matching section before following
anything here.
