## Overview

Install the npm package `@qvac/sdk` in your project. Then, load models and use them to perform AI inference locally, or delegate inference to peers using the built-in P2P capability.

## Description

The JS SDK is cross-platform, type-safe, and pluggable, exposing all QVAC capabilities through a unified interface.

### Key features

- **Cross-platform:** portable code across Linux, macOS, and Windows (Node.js / [Bare runtime](https://bare.pears.com)); Android and iOS ([Expo](https://expo.dev)).
- **Pluggable**: build lean apps by including only what you need, and extend the SDK with custom plugins.
- **Type-safe:** typed JS API.
- **Unified interface:** multiple AI tasks, one single npm package to install in your project.

## Functionalities

### AI tasks

* [**Text generation:**](/sdk/ai-capabilities/text-generation) LLM inference for text generation and chat via [`qvac-fabric-llm.cpp`](https://github.com/tetherto/qvac-fabric-llm.cpp).
* [**Text embeddings:**](/sdk/ai-capabilities/text-embeddings) vector embedding generation for semantic search, clustering, and retrieval, via `qvac-fabric-llm.cpp`.
* [**RAG:**](/sdk/ai-capabilities/rag) out-of-the-box retrieval-augmented generation workflow.
* [**Fine-tuning:**](/sdk/ai-capabilities/fine-tuning) adapting LLMs to domain-specific tasks via LoRA.
* [**Multimodal:**](/sdk/ai-capabilities/multimodal) LLM inference over text, images, and other media within a single conversation context.
* [**Batch processing:**](/sdk/ai-capabilities/batch-processing) run multiple LLM prompts concurrently through a single loaded model in one call.
* [**Image generation:**](/sdk/ai-capabilities/image-generation) text-to-image and image-to-image generation via a customized Diffusion engine.
* [**Video generation:**](/sdk/ai-capabilities/video-generation) text-to-video and image-to-video generation via a customized Diffusion engine.
* [**Transcription:**](/sdk/ai-capabilities/transcription) automatic speech recognition (ASR) for speech-to-text via a customized Whisper engine or [NVIDIA Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2).
* [**Text-to-Speech:**](/sdk/ai-capabilities/text-to-speech) speech synthesis for text-to-speech (TTS) via [a customized GGML backend](https://github.com/tetherto/qvac/tree/main/packages/tts-ggml).
* [**Voice assistant:**](/sdk/ai-capabilities/voice-assistant) real-time voice conversation pipeline chaining transcription, text generation, and text-to-speech.
* [**Translation:**](/sdk/ai-capabilities/translation) text-to-text neural machine translation (NMT), via `qvac-fabric-llm.cpp` and [Bergamot](https://browser.mt).
* [**BCI:**](/sdk/ai-capabilities/bci) brain–computer interface (BCI) transcription that decodes multi-channel neural signals into text, via [a customized Whisper backend](https://github.com/tetherto/qvac/tree/main/packages/bci-whispercpp).
* [**VLA:**](/sdk/ai-capabilities/vla) vision-language-action that turns camera frames, robot state, and natural-language instruction into action chunks for robot control, via [a customized GGML backend](https://github.com/tetherto/qvac/tree/main/packages/vla-ggml).
* [**OCR:**](/sdk/ai-capabilities/ocr) optical character recognition (OCR) for extracting text from images via ONNX runtime.
* [**Image classification:**](/sdk/ai-capabilities/image-classification) assigning class labels with confidence scores to images, via [a customized GGML backend](https://github.com/tetherto/qvac/tree/main/packages/classification-ggml).

### P2P capabilities

* [**Delegated inference:**](/sdk/p2p-capabilities/delegated-inference) delegate inference to peers via the [Holepunch stack](https://holepunch.to), enabling resource sharing.
* **Fetch models:** download AI models from peers via the distributed model registry.
* [**Blind relays:**](/sdk/p2p-capabilities/blind-relays) connect peers across NATs/firewalls by routing traffic through relay nodes.

### Utilities

* [**Logging:**](/sdk/runtime/logging) visibility into what's happening  during loading, inference, and other operations.
* [**Profiler:**](/sdk/runtime/profiler) measure and export timing metrics across model loading, inference, and P2P delegation.
* [**Download Lifecycle:**](/sdk/models/download-lifecycle) pause and resume model downloads.
* [**Runtime lifecycle:**](/sdk/runtime/lifecycle) suspend and resume the SDK runtime (e.g., on app background/foreground) and query lifecycle state.
* [**Cancellation:**](/sdk/runtime/cancellation) cancel any in-flight inference, model load, or download by `requestId`, or broad-cancel by `modelId` for unload/shutdown.
* [**Sharded models:**](/sdk/models/sharded-models) download a model that is sharded into multiple parts.

## Flow

Before you can use a model, you need to load it from some location into memory. Flow for performing AI inference:

1. Call function [`loadModel()`](/sdk/reference/api#loadmodel) to initialize the SDK and load one model. You can load multiple models simultaneously calling `loadModel()` again.
2. Perform AI tasks by calling the appropriate functions from SDK API — e.g., `completion()`.
3. When you are done with a model, call [`unloadModel()`](/sdk/reference/api#unloadmodel) to release computer resources.
4. Finally, close the SDK instance by calling [`close()`](/sdk/reference/api).

## Models

Each [AI task](#ai-tasks) works with different model families, and among the supported ones, you can choose which to use and how to obtain them. `loadModel()` manages the download and caching of models (one or multiple files), and their loading from disk into memory, preparing them for use.

`loadModel()` supports loading models from three different locations:
* Local filesystem, by providing a path.
* HTTP server, by providing an HTTP URL.
* Our distributed model registry.
 
The SDK package does not ship with built-in models, **but** its API exposes constants representing preconfigured models (e.g., `LLAMA_3_2_1B_INST_Q4_0`). Each constant maps a model already published to our model registry. When calling `loadModel()`, you can provide one of these constants instead of a location, making model retrieval transparent.

For more on querying the model registry, see [`modelRegistryList()`](/sdk/reference/api#modelregistrylist), [`modelRegistrySearch()`](/sdk/reference/api#modelregistrysearch), and [`modelRegistryGetModel()`](/sdk/reference/api#modelregistrygetmodel).
